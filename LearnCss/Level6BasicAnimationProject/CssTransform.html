CSS Transform Example

1️⃣ translate() → Move

This moves a box left, right, up, down.

.box {
  transform: translate(50px, 20px);
}
  • ✔ Moves the box 50px right
  • ✔ Moves 20px down

💡 Think: Dragging a photo slightly to adjust position. It does NOT affect other elements.

2️⃣ scale() → Make Bigger or Smaller

.box:hover {
  transform: scale(1.2);
}

When mouse goes over the box → 20% bigger

✔ Used in: Hover effects, Buttons, Cards, Images

💡 Think: Zooming a photo by pinch

3️⃣ rotate() → Rotate the box

.box {
  transform: rotate(10deg);
}

✔ Rotate clockwise 10°

💡 Think: Tilting your phone slightly

⭐ BONUS: Combine Transforms

transform: translateY(-10px) scale(1.1);
  • ✔ Move up
  • ✔ Make bigger

Used in all modern UI cards everywhere.
