Fade, Slide, Pulse, and a Fade+Slide combo ready to use.

Keyframes = story

Define movement + apply

@keyframes moveBox { from { transform: translateX(0); } to { transform: translateX(100px); } } /* Apply to an element */ .box { animation: moveBox 2s ease infinite; }

Keyframes define property changes over time; the animation shorthand binds it to an element. [web:48][web:54]

Fade In

Hero / modal reveal

This text fades in smoothly.
@keyframes fadeIn { from { opacity: 0; } to { opacity: 1; } } .hero-text { animation: fadeIn 1s ease; }
Slide Up

Sections / cards

This block slides up and appears.
@keyframes slideUp { from { transform: translateY(30px); opacity: 0; } to { transform: translateY(0); opacity: 1; } } .section { animation: slideUp 0.8s ease-out; }
Pulse Button

Call‑to‑action highlight

@keyframes pulse { 0% { transform: scale(1); } 50% { transform: scale(1.05); } 100% { transform: scale(1); } } button.cta { animation: pulse 2s ease-in-out infinite; }
Fade + Slide

Modern card entrance

Premium UI Card

Common in React/Next apps: smooth entrance then keep final state.

@keyframes fadeSlide { from { opacity: 0; transform: translateY(20px); } to { opacity: 1; transform: translateY(0); } } .card { animation: fadeSlide 0.6s ease forwards; }

Use forwards to keep the last keyframe after the animation completes. [web:48][web:54]
